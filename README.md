# Stock Portfolio Tracker — CodeAlpha Internship

## Project Overview
A Python-based stock portfolio tracker developed as part of the CodeAlpha Python Programming Internship. The program calculates the total investment value using predefined stock prices and user-entered quantities.

## Features
- Supports predefined stocks: AAPL, TSLA, GOOGL, and MSFT
- Accepts stock symbols and quantities from users
- Validates stock symbols and quantities
- Supports multiple purchases of the same stock
- Calculates individual stock investment values
- Displays the total portfolio investment
- Saves a portfolio report to a text file

## Technologies Used
- Python 3
- Dictionaries
- Loops and conditional statements
- File handling

## How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the Python program using:
   python "StockPortfolioTracker.py"
5. Enter stock symbols and quantities when prompted.
6. View the portfolio summary and the generated `stock_portfolio.txt` report.
